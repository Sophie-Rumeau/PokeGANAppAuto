# PokeGANAppAuto

## Organisation du repository

Ce repository est organise de la facon suivante:

- `main` sert de sommaire global du projet.
- Chaque branche correspond a une piste de travail exploree (experimentation, approche, variante, etc.).

## Regle de maintenance

Le sommaire sur `main` doit etre mis a jour a chaque fois qu'une nouvelle branche de travail est creee ou qu'une piste evolue de maniere significative.

## Etat actuel

Pour le moment, en plus de `main`, il existe la branche `genStats`.

Cette branche `genStats` implemente la piste de generation de statistiques Pokemon decrite dans le document methodology (choix du dataset, modele CTGAN, optimisation des epochs, et resultats).
